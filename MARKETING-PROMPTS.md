# 100 Prompt Marketing — Electra Skill Academy

Kumpulan **100 prompt siap-paste** untuk membuat bahan marketing per produk.
Setiap prompt menjual **satu produk/fitur** (1 simulator = 1 prompt) supaya bisa
jadi banyak konten berbeda.

### Cara pakai
- **GPT / Claude (copywriting):** paste prompt apa adanya → dapat caption, hook, script.
- **Canva (Magic Media / Magic Write):** paste bagian "VISUAL:" untuk gambar, atau
  seluruh prompt untuk teks poster/carousel.
- **Variabel** yang bisa kamu ganti: `{HARGA}` (mis. Rp 299.000), `{WA}` (nomor WA),
  `{LINK}` (electraacademy.com), `{TANGGAL}` (mis. promo).
- Gaya brand: **gold/navy, premium, editorial, Bahasa Indonesia, audiens teknisi &
  fresh graduate elektro Indonesia.** Sebut nyata: PLN, PUIL, SKKNI, K3.

> Tip: tambahkan di akhir tiap prompt → "Buat 3 variasi: (1) untuk Instagram feed,
> (2) untuk TikTok hook 3 detik, (3) untuk LinkedIn profesional."
