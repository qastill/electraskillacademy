# Electra career scenes

Generated with the built-in imagegen tool. These assets are realistic, rendered-looking **four-frame scene sheets**, not rigged 3D models or real-time WebGL animation. The lobby dissolves between the four frames and supports pause and reduced motion.

Each `s1.webp`–`s16.webp` asset contains four equal frames in a 2×2 layout. Only the selected Academy's sheet is downloaded by the page. Total asset size is about 2.4 MB for all 16 scenes. Originals were converted to WebP at quality 85, with any transparency composited against the lobby background.

## Prompt set

Shared generation specification: four equal 16:9 frames in a precise 2×2 contact sheet, no gutters; coherent person, clothing, equipment, background and locked camera; four small sequential work poses returning toward the starting pose; realistic high-budget open-world game rendering, detailed materials and anatomy, cinematic emerald shadows and warm light; no UI, captions, logos or watermarks; safe professional activities. The EV revision explicitly requests opaque, equally lit frames without fades or vignette.
